JSNES 2.1.0

JSNES is a JavaScript NES emulator by Ben Firshman and contributors, based on James Sanders’ vNES. It handles NES emulation, Canvas rendering, Web Audio, keyboard input, and gamepad input. The exact 2.1.0 distribution is hosted with this arcade.
