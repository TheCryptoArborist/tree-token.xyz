JSNES 2.1.0

JSNES is a JavaScript NES emulator by Ben Firshman and contributors, based on James Sanders’ vNES. It handles NES emulation, Canvas rendering, Web Audio, keyboard input, and gamepad input. This arcade hosts version 2.1.0 with a small browser timing patch to bound frame catch-up after file dialogs. The NES core and save-state format are unchanged. Patch details.
