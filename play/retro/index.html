About saves, devices, and this preview

Progress is saved separately for each exact ROM. Use Save progress before leaving, then Resume saved after starting the same game. Clearing website data or using private browsing can remove local saves. Export a save for backup; import it with the same ROM and emulator version.

The preview starts with NES support. Game compatibility, Bluetooth controllers, fullscreen, and performance depend on your device and browser. Some mobile browsers show an expanded player instead of native fullscreen.
