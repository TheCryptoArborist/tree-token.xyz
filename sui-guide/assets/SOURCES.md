# Wallet logo sources

These files are unmodified compact marks from each wallet's official branding resources:

- `slush-symbol.svg`: Slush webclip symbol from https://slush.app/brand-assets
- `phantom-symbol.svg`: Phantom integration icon from https://docs.phantom.com/resources/assets
- `nightly-symbol.svg`: Nightly Wallet dark square mark from https://nightly.app/branding
