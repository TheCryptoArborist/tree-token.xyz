Skill rules & verification

Scoring

Correct answers are the primary score. Server-recorded elapsed time is the secondary score. An incorrect fast submission cannot outrank a slower submission with more correct answers.

Verification

The server verifies the qualifying purchase, wallet authorization, unused Challenge Pass, server start time, deadline, submitted answers, and score before a result can enter the leaderboard.

Live competition flow

Each qualifying wallet can enter once per daily round. The wallet must complete its one timed, non-repeatable attempt for the result to enter the standings.

verified $5+ TREE purchase → one Challenge Pass → one scored attempt → three questions in 90 seconds → locked score + time → sudden death if needed → one daily winner
